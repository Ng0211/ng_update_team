# Assets Folder

This folder contains all the images and assets used by the SAC IIT Delhi website.

## Required Images

### Home Page
- `sac_logo.png` - SAC logo image
- `iit_delhi.jpeg` - IIT Delhi campus image for hero background
- `about-us_background.png` - Background image for about section
- `sac_centre_bg_removed.png` - Central SAC image for three-column layout

### SAC Boards
- `bhm_logo.png` - Board for Hostel Management logo
- `brca.png` - Board for Recreational and Creative Activities logo
- `bsw_logo.png` - Board for Student Welfare logo
- `bsa.png` - Board for Student Activities logo
- `bsp_logo.png` - Board for Student Publications logo
- `IITDClubs.png` - IIT Delhi Clubs logo

### Activities Page
- `cultural_festival.jpg` - Cultural festival image
- `technical_summit.jpg` - Technical summit image
- `sports_meet.jpg` - Sports meet image
- `freshers_welcome.jpg` - Freshers welcome image
- `alumni_meet.jpg` - Alumni meet image
- `research_symposium.jpg` - Research symposium image

## Image Requirements
- Use PNG format for logos and transparent images
- Use JPG format for photographs and background images
- Optimize images for web (recommended max size: 2MB)
- Maintain aspect ratios for consistent display

## Placeholder Images
If any of these images are not available, the website will automatically use placeholder images from placeholder.com service.
